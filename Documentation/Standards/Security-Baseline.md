# Security Baseline

The following controls are implemented within the Futurion Systems Active Directory environment.

---

## Identity

- Active Directory Authentication
- Strong Password Policy
- Account Lockout
- Least Privilege

---

## Endpoint Security

- Windows Defender
- Windows Firewall
- Automatic Updates

---

## Network Security

- Static IP Addressing
- DNS Protection
- DHCP Management

---

## Administration

- PowerShell Logging
- Event Viewer Monitoring
- Administrative Separation

---

## Future Enhancements

- Microsoft Entra ID
- Multi-Factor Authentication
- Microsoft Sentinel
- Conditional Access
