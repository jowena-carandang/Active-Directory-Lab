# 🛣️ Infrastructure Roadmap

## Overview

As Futurion Systems continues to grow, its IT infrastructure must evolve to support increasing business demands, strengthen security, and improve operational efficiency. This roadmap outlines the planned implementation of core Microsoft technologies that will modernize the company's environment while establishing a secure and scalable foundation for future growth.

Each phase represents a realistic business initiative and builds upon the previous implementation. Together, these projects demonstrate the progression from a traditional on-premises infrastructure to a modern hybrid cloud environment.

---

## Roadmap

| Phase | Project                            | Description                                                                                                                                                               |    Status   |
| :---: | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------: |
| **1** | Active Directory Infrastructure    | Deploy Active Directory Domain Services (AD DS), DNS, DHCP, Organizational Units, security groups, and Group Policy Objects to centralize identity and device management. | ✅ Completed |
| **2** | File Services & Shared Resources   | Implement a dedicated file server with departmental shared folders, NTFS permissions, and centralized file management.                                                    |  ⏳ Planned  |
| **3** | Microsoft 365 & Microsoft Entra ID | Introduce cloud identity, Microsoft 365 services, Multi-Factor Authentication (MFA), and hybrid identity management.                                                      |  ⏳ Planned  |
| **4** | Microsoft Azure Infrastructure     | Extend the on-premises environment into Azure using virtual machines, storage services, networking, and backup solutions.                                                 |  ⏳ Planned  |
| **5** | Security Operations Center (SOC)   | Deploy Microsoft Sentinel to centralize log collection, security monitoring, and incident response.                                                                       |  ⏳ Planned  |
| **6** | Vulnerability Management           | Perform vulnerability assessments, prioritize security risks, and establish a structured remediation process.                                                             |  ⏳ Planned  |
| **7** | Backup & Disaster Recovery         | Implement backup, recovery, and business continuity solutions to improve resilience against system failures and cyber threats.                                            |  ⏳ Planned  |

---

## Project Objectives

The infrastructure roadmap is designed to achieve the following objectives:

* Establish centralized identity and access management.
* Improve security through standardized policies and role-based access control.
* Support business growth with scalable Microsoft technologies.
* Prepare the organization for hybrid cloud adoption.
* Enhance security monitoring and incident response capabilities.
* Ensure business continuity through reliable backup and disaster recovery solutions.

---

## Portfolio Vision

This roadmap provides a structured plan for the ongoing development of Futurion Systems' IT environment. Each completed phase represents a practical business project and demonstrates the planning, implementation, and documentation expected of a Systems Administrator working within a modern Managed Service Provider (MSP).
