# Infrastructure Roadmap

The Futurion Systems environment will be developed in phases to simulate the growth of a real enterprise.

---

## Phase 1

Enterprise Active Directory

- Windows Server

- DNS
- DHCP
- Organizational Units
- Group Policy

---

## Phase 2

Windows Administration

- File Server
- NTFS Permissions
- Shared Folders
- Printer Management
- Backup

## Phase 3

PowerShell Automation

- Password Reset
- Reporting
- Bulk Administration

## Phase 4

Azure

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Storage
- RBAC

Security Operations

- Log Analytics
- Incident Response

Security Hardening

- MFA

## Phase 7

Enterprise Documentation

- Asset Inventory
