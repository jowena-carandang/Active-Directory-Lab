# Active Directory Home Lab

## Overview

This project documents the design, implementation, and administration of a Windows Server Active Directory environment built in a virtual lab.

The goal of this project is to develop practical experience with enterprise identity management, Windows administration, networking, Group Policy, and PowerShell.

---

## Project Objectives

- Deploy Windows Server
- Install Active Directory Domain Services (AD DS)
- Configure DNS
- Configure DHCP
- Create Organizational Units
- Create users and groups
- Join Windows clients to the domain
- Configure Group Policy
- Implement shared folders and NTFS permissions
- Automate administrative tasks using PowerShell
