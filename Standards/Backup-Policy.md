# Backup Policy

## Objective

Protect business-critical systems and data.

---

## Backup Schedule

Daily Incremental Backup

Weekly Full Backup

Monthly Archive

---

## Backup Targets

- Active Directory
- DNS
- DHCP
- File Shares
- PowerShell Scripts
- Documentation

---

## Recovery Objectives

Recovery Time Objective (RTO):
4 Hours

Recovery Point Objective (RPO):
24 Hours

---

Azure Backup

Offsite Backup
